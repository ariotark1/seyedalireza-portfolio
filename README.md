# seyedalireza.me

یک وب‌سایت شخصی ایستا و واکنش‌گرا، راست‌چین و فارسی. به نصب ابزار یا دیتابیس نیاز ندارد.

## تغییر اطلاعات

اطلاعات عمومی را در `profile.js` وارد کن: معرفی کوتاه، شبکه‌های اجتماعی، راه تماس، تجربه، تحصیلات، مهارت‌ها و پروژه‌ها. برای افزودن اطلاعاتی که هنوز قطعی نیستند، مقدار خالی بگذار تا لینک نامعتبر نمایش داده نشود.

دکمهٔ «ذخیره یا چاپ رزومه» پنجرهٔ چاپ مرورگر را باز می‌کند؛ در آنجا می‌توان گزینهٔ ذخیره به PDF را انتخاب کرد.

## انتشار

این پوشه فایل‌های استاتیک است و می‌تواند روی هر میزبانی وب ساده قرار بگیرد. برای اتصال دامنه، ابتدا هاست را انتخاب کن و سپس رکورد DNS یا نیم‌سرورهایی را که همان هاست می‌دهد در Namecheap تنظیم کن. تا وقتی هاست انتخاب نشده، DNS دامنه را تغییر نده.
